Apresentação

Clínica Vida+ — projeto acadêmico completo

O projeto demonstra como requisitos de uma clínica fictícia podem ser traduzidos em planejamento ágil, programação, regras lógicas, processamento em fila e modelagem de sistema. Os dados e exemplos são fictícios e não representam pacientes reais nem informações médicas.

Objetivo geral

Desenvolver uma visão integrada de organização de tarefas e fundamentos de programação aplicados ao contexto de gestão de consultas.

Objetivos específicos

  • Planejar entregas com sprints e acompanhamento visual.
  • Implementar cadastro e estatísticas com listas e dicionários em Python.
  • Validar regras de liberação por tabelas-verdade completas.
  • Demonstrar fila FIFO com três pacientes fictícios.
  • Representar atores, casos de uso e limites do sistema.

Programa Python — cadastro de pacientes

Código real em Python 3, com listas e dicionários, menu em loop e tratamento de entradas inválidas.

Baixar clinica_vida.py

Funcionalidades

  1. Cadastrar paciente: nome, idade e telefone.
  2. Ver estatísticas: total, idade média, mais novo e mais velho.
  3. Buscar paciente pelo nome, sem diferenciar maiúsculas.
  4. Listar todos os pacientes.
  5. Sair do programa.

Como executar

Salve o arquivo clinica_vida.py e execute no terminal:

python clinica_vida.py

Em alguns sistemas Linux/macOS, use python3 clinica_vida.py. Requer Python 3 e não precisa de bibliotecas externas.

Lógica proposicional — liberação de atendimento

V = verdadeiro; F = falso. As tabelas exibem todas as 16 combinações possíveis.

Variáveis

  • A = tem agendamento
  • B = documentos válidos
  • C = médico disponível
  • D = pagamentos em dia

Consulta normal

(A ∧ B ∧ C) ∨ (B ∧ C ∧ D)

Fatorando, equivale a B ∧ C ∧ (A ∨ D): documentos válidos e médico disponível, com agendamento ou pagamentos em dia.

Emergência

C ∧ (B ∨ D)

O médico precisa estar disponível e ao menos uma das condições B ou D deve ser verdadeira, conforme a regra definida para este exercício.

Tabela-verdade — consulta normal

Tabela-verdade — emergência

Algoritmo — fila FIFO

FIFO significa “First In, First Out”: o primeiro elemento inserido é o primeiro removido.

Pseudocódigo

INÍCIO criar fila vazia inserir no final da fila: ("Ana Exemplo", "CPF-001") inserir no final da fila: ("Bruno Modelo", "CPF-002") inserir no final da fila: ("Caio Demonstração", "CPF-003") escrever "Fila inicial:", fila paciente_atendido ← remover_do_início(fila) escrever "Paciente chamado para atendimento:", paciente_atendido escrever "Fila restante:", fila FIM

CPFs mascarados e nomes são identificadores fictícios usados somente para demonstrar a estrutura; não correspondem a pessoas reais.

Encerramento

Conclusão

O projeto Clínica Vida+ conecta cinco fundamentos complementares: planejamento ágil, programação estruturada, lógica proposicional, filas FIFO e UML. O quadro permite acompanhar tarefas e produzir relatórios; o programa Python realiza operações reais no terminal; as tabelas-verdade verificam todas as combinações das regras; o algoritmo ilustra a ordem de atendimento; e o diagrama explicita os atores e os limites do sistema.

Referências e ferramentas utilizadas

  • Python 3 — documentação oficial: docs.python.org/3.
  • Trello — ferramenta de organização visual: trello.com. O quadro desta aplicação não sincroniza com uma conta Trello.
  • UML — notação de modelagem de sistemas; diagrama de casos de uso representado em SVG.
  • HTML5, CSS3 e JavaScript — interface web responsiva, tabelas-verdade, interação com quadro e exportação local.

Aviso acadêmico: dados fictícios para demonstração. Não inserir informações pessoais ou médicas reais nesta versão.
